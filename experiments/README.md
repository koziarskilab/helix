# Experiments

Runners and evaluation scripts to reproduce results from HELiX paper.

## Layout

```
experiments/
├── train_helix.py             # run HELiX w/o BO
├── run_helix.py               # run HELiX w/ BO
├── eval.py                    # post-hoc metrics (num scaffolds modes, etc.)
├── estimate_state_space.py    # estimate library sizes
├── data/
│   ├── concat/                # fragment libraries
│   └── initial_hits/
├── results/                   # outputs, grouped by experiment
└── utils/
    ├── factory.py             # gin-configurable model/oracle/acquisition
    ├── paths.py               # path layout
    └── metrics.py
```

## Quick start

```bash
# Run baseline w/ sEH oracle, initial hit 0
python experiments/run_helix.py \
    --cfg configs/experiments/baselines.gin \
    --oracle seh \
    --hit 0

# Evaluate
python experiments/eval.py \
    --experiment baselines \
    --model helix \
    --oracle seh \
    --hit 0
```

## Data

### Libraries

HELiX requires a library of fragments (building blocks) and reaction templates. The following libraries were used for running experiments in the paper:

**SMALL:** 418 building blocks, 112 reaction templates, taken from the SMALL setting of RGFN. Default library for all main experiments. Stored at `data/small/` (used as baseline library for generic runs).

**CONCAT:** 128k fragments with the same 112 templates. Used for library ablations and scaling experiments. Stored at `experiments/data/concat/`. The fragments are taken from the Enamine REAL Database and are available upon request (see [here](https://enamine.net/compound-collections/real-compounds/real-database) or contact authors).

The CONCAT sub-sampled libraries (`fragments_{2,4,8,16,32,64}k.txt`) each include the full SMALL fragment set plus a random subset of the remaining CONCAT fragments. This ensures any hit decomposable under SMALL is also decomposable under the other libraries.

### Initial hits

10 starting molecules per oracle (sEH, GSK3$\beta$, JNK3), generated by clustering the top molecules sampled from a pre-trained SCENT model (see Appendix B in the paper for the full procedure). Stored at `experiments/data/initial_hits/{oracle}_hits.csv` with a `molecule` column indicating SMILES.

`projection_hits.csv` contains the 5 ChemProjector-derived hits used in Appendix D.5.


## Reproducing experiments

### 4.1 - Baseline comparison

**Run HELiX:**

```bash
for oracle in seh gsk jnk3; do
  for hit in {0..9}; do
    python experiments/run_helix.py --cfg configs/experiments/baselines.gin \
        --oracle $oracle \
        --hit $hit
  done
done
```

Results are stored at `results/baselines/helix/{oracle}/hit_{i}.csv`.

**Baselines:** REINVENT4, SynFormer-ED, TRACER, SynGA, ReaSyn, and SCENT were generated from their respective upstream codebases and placed into `results/baselines/{baseline}/{oracle}/hit_{i}.csv` following the same schema.

**Evaluate:**

```bash
for oracle in seh gsk jnk3; do
  for hit in {0..9}; do
    python experiments/eval.py \
        --experiment baselines \
        --model helix \
        --oracle $oracle \
        --hit $hit
  done
done
```

Repeat with `--model {model}` for `reinvent`, `synformer`, etc. Each evaluation run produces `hit_{i}_metrics.csv` alongside `hit_{i}.csv`.

### 4.4 - Robustness to unreliable oracles

Sweeps additive Gaussian noise $\sigma \in \{0.1, 0.5, 1.0, 2.0\}$ on sEH. Compares HELiX against SCENT.

**Run HELiX:**

```bash
for noise_std in 0.1 0.5 1.0 2.0; do
  for hit in {0..9}; do
    python experiments/run_helix.py \
        --cfg configs/experiments/noisy_proxy/noise_${noise_std}.gin \
        --oracle seh \
        --hit $hit
  done
done
```

Results are stored at `results/noisy_proxy/helix/seh/noise_${noise_std}/hit_{i}.csv`. SCENT runs are stored at `results/noisy_proxy/scent/seh/noise_${noise_std}/`.

**Evaluate:**

```bash
for noise_std in 0.1 0.5 1.0 2.0; do
  for hit in {0..9}; do
    python experiments/eval.py \
        --experiment noisy_proxy \
        --model helix \
        --oracle seh \
        --variant noise_${noise_std} \
        --hit $hit \
        --noisy
  done
done
```

`--noisy` re-scores against the clean oracle (runs save noisy scores during training). Figure 6 plots the `top10_mean` column (no similarity constraint) minus the noise-free baseline from Section 4.1.

### Appendix C - State space estimation

Estimates the size of the chemical space accessible to HELiX as a function of fragment library size and trajectory length.

```bash
python experiments/estimate_state_space.py \
    --libraries small concat_2k concat_4k concat_8k concat_16k \
    --n_samples 10000
```

Writes one JSON per library to `results/space_estimation/{library}.json`. The SCENT reference is computed separately, stored at `results/space_estimation/scent.json`.

### E.1 - BO ablation

Compares HELiX with and without BO. The BO setting is run in the baseline comparison; only the non-BO setting needs to be run here.

**Run HELiX (no BO):**

Use `experiments/train_helix.py` to run w/o BO:

```bash
for hit in {0..9}; do
  python experiments/train_helix.py \
    --cfg configs/experiments/bo_ablations/helix.gin \
    --oracle seh \
    --hit $hit
done
```

Results are stored at `results/bo_ablations/helix/seh/hit_{i}.csv`. SCENT runs (with and without BO) are stored at `results/bo_ablations/scent{,_bo}/seh/`.

**Evaluate:**

```bash
for hit in {0..9}; do
  python experiments/eval.py \
    --experiment bo_ablations \
    --model helix \
    --oracle seh \
    --hit $hit
done
```

### E.4 - Library size and scaling

**Library comparison:** runs HELiX on the full CONCAT library (128k fragments).

```bash
for hit in {0..9}; do
  python experiments/run_helix.py \
    --cfg configs/experiments/lib_ablations.gin \
    --oracle seh \
    --hit $hit
done
```

Results are stored at `results/lib_ablations/helix/seh/hit_{i}.csv`. SynFormer-ED and SCENT stored at `results/lib_ablations/{synformer,scent}/seh/`.

```bash
for hit in {0..9}; do
  python experiments/eval.py \
    --experiment lib_ablations \
    --model helix \
    --oracle seh \
    --hit $hit
done
```

**Library scaling:** sweeps the CONCAT library size from 2k to 64k fragments (not included in final manuscript).

```bash
for size in 2k 4k 8k 16k 32k 64k; do
  for hit in {0..2}; do
    python experiments/run_helix.py \
        --cfg configs/experiments/library_scaling/concat_${size}.gin \
        --oracle seh \
        --hit $hit
  done

  for hit in {0..2}; do
    python experiments/eval.py \
        --experiment library_scaling \
        --model helix \
        --oracle seh \
        --variant concat_${size} \
        --hit $hit
  done
done
```

Results: `results/library_scaling/helix/seh/concat_${size}/hit_{i}.csv`.
